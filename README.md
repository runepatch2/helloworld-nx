Basic program that allows you to count how many times you've printed Hello, World!
It saves your count in "sdmc:\switch\count.txt" and saves all of the Hello, World!'s in "sdmc:\switch\output.txt"

Visit https://gist.github.com/joshenders/4e43259eb641ce2342dea9416154c2c1 and https://switch.hacks.guide/ for information
on how to run this on your switch (and how to mod and unpatched switch 1 if you have one!)
